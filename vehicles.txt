# ============================================
# 車款資料檔 - 用記事本打開這個檔案就能編輯
# ============================================
#
# 規則：
# 1. 一輛車一行，欄位之間用「|」符號分開，順序固定是：
#    車款名稱 | 年份 | 里程 | 排氣量 | 價格 | 照片檔名
#
# 2. 照片請先放到 images 資料夾裡，這裡只要填「檔名」就好
#    例如照片放在 images/dio001.jpg，這裡就填 dio001.jpg
#    如果還沒有照片，這欄留空白也可以（會顯示「車輛照片」佔位圖）
#
# 3. 價格請直接填數字，不用加 NT$ 或逗號，網頁會自動加上
#
# 4. 開頭是 # 的整行都是說明文字，不會顯示在網頁上
#
# 5. 改完存檔後，跟 Claude 說一聲「更新車款」，就會幫你推送上線
#
# ============================================
# 下面是範例資料，直接複製一行改成你的車款即可：
# ============================================

YAMAHA R3 ABS | 2021 | 3000 km | 300cc | 99,000 | CAR01.jpg
JETSL158 | 2024 | 10000 km | 158cc | 88,000 | CAR02.jpg
